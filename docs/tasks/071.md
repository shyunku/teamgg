## 기록

### 범위 결정

- 2026-10-03 15:55: 룬 테이블 `match_participant_perks`(약 1,031만 행)와 `match_participant_perk_styles`(약 1,884만 행)는 제외한다. #65 룬 평탄화가 이 테이블들을 참가자당 한 행 구조로 다시 만들 예정이므로, 숫자 participant 키 기반 새 구조로 바로 옮겨 대형 테이블 UPDATE와 binlog·디스크 증가를 한 번 줄인다. 신규 행은 기존 trigger로 계속 숫자 FK가 채워진다.

- 2026-09-02 02:41 — #64에서 분리해 등록했다.
- 2026-10-03 15:55 — 룬 테이블 제외를 사용자와 결정했다.
- 2026-10-04 15:30 — `backfill-numeric-keys` 하위 단계 대상과 readiness 검증에서 룬 테이블을 뺐다. `NUMERIC_KEY_BACKFILL_STOP_AFTER_PARTICIPANTS=true`면 참가자 단계 완료 직후 부모 검증 스캔과 하위 단계를 건너뛰고 끝난다. 격리 MySQL 통합 테스트로 참가자 전용 실행이 하위 진행 상태를 쓰지 않고, 일반 실행이 legacy 룬 행을 건드리지 않음을 검증했다. 백엔드 전체 테스트와 vet을 통과했다. 운영 이미지에는 아직 반영하지 않았다.
