### 구현

- `cleanup-retention` 유지보수 명령과 [운영 문서](../operations/data-retention-operations.md)를 추가했다.
- 사용자 계정·내전·리플레이 데이터와 stale 소환사는 삭제 대상에서 제외했다.
- 대형 테이블의 full scan을 피하도록 PK 기반 join delete로 최적화했다.
- 숫자 match/participant identity는 상세 캐시가 아니므로 삭제하지 않고 재수집 시 동일 ID를 재사용한다.
- 전체 Go 테스트·vet·build와 임시 MySQL DB 통합 테스트를 통과했다.
