## 기록

### 실행 방식

- `backfill-numeric-keys`를 백엔드 무중단으로 실행한다. PK 순서 keyset 500건 배치, 부모 identity 선점, `binlog_row_image=MINIMAL`, READ COMMITTED.
- 2026-08-31 이후 저장된 participant는 trigger로 숫자 키가 채워지므로 그 이전 행만 대상이다.
- 실행 스크립트가 30초마다 API 응답·DB 실행 스레드·락 대기를 기록하고, 디스크 여유가 15GiB 아래로 내려가면 컨테이너를 멈춘다.
- 명령은 참가자 단계가 끝나면 하위 관계(#71) 단계로 자동 진행하므로, 별도 감시 스크립트가 참가자 완료 시점에 컨테이너를 멈춘다.
