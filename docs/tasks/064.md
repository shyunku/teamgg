## 완료 범위

- 숫자 identity·백필 진행 테이블과 신규 쓰기 동기화 기반 구축
- `summoners`, `matches` 부모 숫자 키 백필 완료
- `masteries_numeric_v2` 생성 및 운영 데이터 전환
- 숙련도 조회·집계의 `numeric_v2` 읽기 전환
- legacy fallback과 시작 시 readiness 검증 제공

Participant 및 나머지 하위 관계 전환은 #70~#72로, legacy 제거는 #73~#75로 분리했다.

## 구조

```text
쓰기: Riot 갱신 → masteries → trigger → masteries_numeric_v2
읽기: backend → masteries_numeric_v2
롤백: MASTERY_READ_SOURCE=legacy
```

현재는 legacy가 쓰기 원본이므로 기존 `masteries`는 아직 제거할 수 없고 디스크 공간도 반환되지 않았다.

## 성능 비교

## 주요 결정

| 결정 | 이유 |
|---|---|
| `masteries` in-place UPDATE 제외 | 대형 rewrite·binlog·디스크 고갈 방지 |
| PK keyset 복사 | OFFSET 및 O(n²) 재스캔 방지 |
| covering index 후생성 | 복사 중 secondary index 유지 비용 제거 |
| checksum 통과 후 trigger 설치 | 불완전 shadow 사용 방지 |
| feature flag 유지 | 즉시 legacy rollback 지원 |
