## 기록

### 결과

| 구분 | 결과 |
|---|---|
| 숙련도 행 | 43,275,694행 복사 |
| 정합성 | 전체 행 수·checksum 일치 |
| 새 테이블 | `masteries_numeric_v2`, 약 4.98GiB |
| 동기화 | legacy INSERT/UPDATE/DELETE trigger 3개 |
| 운영 읽기 | `MASTERY_READ_SOURCE=numeric_v2` |
| 운영 상태 | backend healthy, 관련 오류 없음, 소환사·champion·meta-summary API 200 |

완료 당시 구조는 다음과 같았다. 이후 #73에서 쓰기를, #74에서 legacy 제거를 마쳤다.

```text
쓰기: Riot 갱신 → masteries → trigger → masteries_numeric_v2
읽기: backend → masteries_numeric_v2
롤백: MASTERY_READ_SOURCE=legacy
```

### 성능 비교

운영 DB에서 같은 표본을 번갈아 실행했으며 모든 결과가 일치했다.

### 주요 결정

| 결정 | 이유 |
|---|---|
| `masteries` in-place UPDATE 제외 | 대형 rewrite·binlog·디스크 고갈 방지 |
| PK keyset 복사 | OFFSET 및 O(n²) 재스캔 방지 |
| covering index 후생성 | 복사 중 secondary index 유지 비용 제거 |
| checksum 통과 후 trigger 설치 | 불완전 shadow 사용 방지 |
| feature flag 유지 | 즉시 legacy rollback 지원 |
